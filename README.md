# GitHub Pages
## Práctica 'ACTIVDAD 3'

Trabajo de despliega de aplicaciones web GitHub Pages.Utilizando uno de los repositorios de GitHub del módulo, realiza los siguientes pasos:

- Crea una nueva rama denominada gh-pages a partir de la rama main/master de tu rep itorio.
- Sitúate en esta nueva rama y elimina todo su contenido.
- Incluye en su interior el archivo README.md con contenido descriptivo del proyecto.
- Habilita el uso de GitHub Pages en la configuración de tu repositorio y comprueba que el contenido se muestra correctamente al acceder a la URL del repositorio.

Como resultado de la actividad, adjunta una memoria con todos los pasos realizados, incluyendo breves explicaciones y capturas de pantalla así como el link a la pagina de github.
